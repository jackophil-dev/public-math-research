# H01 — Base Cohomology and Cycle Classes

**Researcher:** Philippe Beauchamp  
**ORCID:** 0009-0003-7407-394X  
**Track:** Hodge / Weil-type abelian fourfolds

## 1. Certificate ID

**CERT-H01 — Base Cohomology and Cycle Classes**

## 2. Theorem Statement

For a smooth projective complex variety, an algebraic cycle determines a cohomology class under the standard cycle-class construction. For a codimension-(p) cycle on a smooth projective variety (X), its Betti class lies in (H^{2p}(X,mathbf Z)) and, after passage to (mathbf Q), is a Hodge class of type ((p,p)).

This certificate records the standard cycle-class layer used by the research program. It is not a claim that every Hodge class is algebraic.

## 3. Definitions / Hypotheses

- (X) is smooth and projective over (mathbf C).
- (Z^p(X)) denotes codimension-(p) algebraic cycles modulo rational equivalence when appropriate.
- The cycle-class map is considered in Betti cohomology, with rational coefficients where stated.
- The Hodge condition concerns the ((p,p))-component of (H^{2p}(X,mathbf C)).

## 4. Calculation / Proof

The cycle class of an algebraic subvariety is represented by its fundamental cohomology class. Linearity extends the construction to algebraic cycles. The compatibility of the class with the Hodge decomposition gives a class of type ((p,p)).

The research program uses this standard map as its entry point before introducing explicit integral lattices, CM actions, Gram matrices, and discriminant data.

## 5. Reproducibility Checkpoint

Verify independently:

1. the codimension (p);
2. the target (H^{2p}(X,mathbf Z)) or (H^{2p}(X,mathbf Q));
3. the Hodge type ((p,p));
4. the compatibility of the cycle-class construction with addition of cycles.

**PROVED — standard mathematical construction.**

## 7. Explicit Scope Limitation

This certificate does **not** prove surjectivity of the cycle-class map onto the Hodge classes and therefore does not prove the Hodge Conjecture.
