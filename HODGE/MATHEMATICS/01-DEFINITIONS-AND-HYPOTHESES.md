# Hodge — Definitions and Hypotheses

Let \(X\) be a complex abelian fourfold of Weil type with an action by an imaginary quadratic field; the recorded model uses \(K=\mathbb Q(i)\). The exact polarization, action on \(H^1\), and integral basis must be fixed before model-specific claims can be checked.

A Hodge class is a rational cohomology class of type \((p,p)\). Algebraic cycle classes form a subgroup of Hodge classes; equality of these groups is not assumed in general.

For an integral lattice \(L\) with non-degenerate Gram matrix \(G\), define
\[
L^*=\{x\in L\otimes\mathbb Q:(x,L)\subseteq\mathbb Z\},\qquad A_L=L^*/L.
\]
Then \(|A_L|=|\det G|\), and the group structure is read from the SNF.

Every computation must state basis order, pairing/sign convention, input provenance, and whether the lattice is known to be saturated. Labels: **PROVED**, **DERIVED**, **COMPUTATIONALLY VERIFIED**, **OPEN**. A lattice calculation is not automatically a geometric cycle identification.
