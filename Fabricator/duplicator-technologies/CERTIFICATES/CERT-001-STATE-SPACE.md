# CERT-001 — State-Space Initialization

## Objective

Define baseline coordinates, admissible states and initialization conditions.

## Specification

\[
D_0=\{s\in\mathbb R^n\mid g_i(s)\le0,\ i=1,\ldots,m\}.
\]

Initialization requires

\[
s(0)\in D_0.
\]

## Status

**SPECIFICATION / OPEN VALIDATION**

The certificate defines what must be checked; it does not claim that a physical implementation has already passed the check.
