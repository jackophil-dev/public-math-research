## Architecture

**Measurement → Comparison → Correction → Invariant/Safety Checks → Execution Decision**

The certificate series addresses state-space initialization, resource bounds, feedback logic, invariant preservation, and execution-safety gate. These documents specify conditions an implementation would need to satisfy. They do not establish a working universal material replicator, validated arbitrary-matter reconstruction, or experimental performance.
