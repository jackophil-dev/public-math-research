# Certificate 07 — Calibration \(\mathbb Q(i)\) dans le modèle décomposable \(J\times J\)

**Auteur de la recherche : Philippe Beauchamp**  
**Assistance au calcul : ChatGPT**  
**Statut : VALIDÉ DANS LE MODÈLE DÉCOMPOSABLE EXPLICITE**

## Objet

Calibration du secteur de Weil dans le modèle décomposable
\[
J\times J
\]
pour
\[
K=\mathbb Q(i).
\]

Dans les conventions utilisées, le secteur de Weil est engendré rationnellement par
\[
W_K=\mathbb Q\alpha_1\oplus\mathbb Q\alpha_2.
\]

Les vecteurs sont représentés dans la base explicite de \(\Lambda^2\) utilisée dans le calcul.

## Résultat

La calibration obtenue est
\[
\boxed{W_K=\mathbb Q\alpha_1\oplus\mathbb Q\alpha_2}.
\]

Le résultat est validé **dans le modèle décomposable explicite** et avec les conventions de polarisation/bases fixées pour ce calcul.

## Limitation

Ce certificat établit la calibration du modèle calculé; il ne démontre pas à lui seul une identification géométrique générale ni une résolution de la conjecture de Hodge.

## Reproductibilité

Le calcul peut être vérifié à partir des matrices de cup-produit/intersection et des générateurs \(\alpha_1,\alpha_2\) des notes de recherche correspondantes.
